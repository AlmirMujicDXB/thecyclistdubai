# TheCyclistDubai Weather: project notes

Live site: https://thecyclistdubai.com/ (GitHub Pages from `main`, workflow `.github/workflows/static.yml`).

## Files
- `index.html`: the whole weather page (HTML, CSS, JS in one file).
- `site-data.js`: sponsors, events and group rides. Edit content here, not in `index.html`.
- `tracks/*.json`: track geometry from OpenStreetMap, refreshed weekly by `.github/workflows/tracks.yml` (`scripts/fetch_tracks.py`).
- `disclaimer.html`: data sources and disclaimer. `quiz.html`: group ride etiquette quiz.

## Rules (from the site owner)
- **When any detail in a card/window changes (time, date, distance, place, pace, links, codes, names), every share output must show the same new detail**: the card on the page, the Share menu row, the share image (`drawCard` / map image), the share message text (`rideText`, `eventText`, `weatherText`, `sponsorText`) and the "next group ride" / "upcoming events" lines inside the weather message. Check all of them before pushing.
- **When the owner adds a new group ride, always ask: is it a one-time ride or recurring (weekly)?** Recurring rides use `weekly: 'Day'`; they move to the same day and time next week automatically as soon as the start time passes. Never ask the owner to update dates of recurring rides. Keep a recurring ride's time unchanged week to week until the owner says otherwise. One-time rides use `date:` and disappear once their start time passes. A recurring ride with a limited run uses `until: 'YYYY-MM-DD'` (TCD Ride: Tuesdays 7:00 AM, Road · 36 km, 30 km/h avg, start BOTS, until 2027-03-23). The Saturday ride was removed.. Rides are always listed soonest first, so the next ride is at the top.
- Events: same card shape/size for every event; `theme: 'yellow'` gives the L'Étape Dubai card in Tour de France colours (maillot-jaune yellow #ffcf00→#ffe100→#fff16a, red #e2001a/#d0001a King-of-the-Mountains polka dots on the right, white date tile with red day, red star/Register button, dark text; no black on buttons/date/star) and yellow share image, default is blue. `code`/`discount` show as a code chip on the card and in every share of that event. Every ride share promotes ALL upcoming events ("📅 Upcoming events": name, date, distance, link, code if any), including any event added later; the weather share lists them too. All event shares use ONE format (eventText/shareEvent/eventPromoText): name, ★ tag, date · time, distance · route, note, days to go, "💪 TheCyclistDubai is taking part" (every event unless `weRide: false`), code (if any), "📝 Register: link". The weather share and ride shares use the same event list (eventPromoText). The events section on the page has an "Events" heading styled like "Group rides". `theme: 'lime'` = Spinneys Dubai 92 Cycle Challenge card (light cream→lime with Spinneys diagonal stripes #00482a/#b5cc4a/#c4d24c, dark-green text, white date tile, dark-green star/button; share image same with stripes bottom-right). Spinneys Dubai 92: Sun 7 Feb 2027, 92 km, Expo City Dubai, start time not announced (no `time` → 'time TBC'), https://cyclechallenge.ae/. L'Étape Dubai by Tour de France: Sun 21 Mar 2027 6:30 AM, register https://haku.ly/e1265eb830, code THECYCLISTDUBAI15 (15% OFF).
- Prefer changing data in `site-data.js` so the page and all share outputs update together. For a one-off ride change use the ride's `changes` entry, e.g. `'2026-11-21': { time: '06:00' }` or `{ cancelled: true }`.
- Sponsors are **not shown on the website** (no sponsor cards or empty sponsor slots). Sponsors live only in shares: ride shares, weather/map shares and the Share menu's "Sponsor codes" option include every sponsor with link and discount code (from `site-data.js`). Event shares contain only the event details (no sponsors, site link or group link).
- Share messages: do not repeat the WhatsApp group link (it is in the footer once). Weather and ride shares include the site link and all sponsor codes.
- Cards (event, group ride) and the header keep the same height (70px desktop, 126px phone); measure every card, not just the first, after content changes. Corners are rounded rectangles, not round pills.
- Order: the "Group rides" section lists the rides by date (no sponsor card between them). All rides use the identical format: tags "⛑️💡 Lights & helmet mandatory (site-wide rideRule in site-data.js) · type · distance · pace", title "Name · time · place", details "Start · forecast"; the same order of facts in every share output. No "New time" tag.
- Theme = UAE Tour WHITE jersey: white dominates, greys and blue, NO black anywhere. Text is slate grey (#334155, secondary #64748b); blue #2563eb/#3b82f6 with light blues #eff6ff/#dbeafe/#bfdbfe/#93c5fd. Header: white→pale-blue background, blue band at the left edge, faint blue/grey dunes + blue dotted route, grey→blue stripe along the bottom, blue "Dubai", blue "Ride Weather" chip, blue clock dot, white social buttons with light blue-grey border. Selected buttons (`--th-*`): blue gradient (#1d4ed8→#2563eb→#3b82f6); field icons blue on pale blue. No red/green/gold/black in the header.
- Header UAE Tour live counter (`.uaet`, `utRender`/`utInit`/`utCycle`, data in `site-data.js` → `uaeTour`): white-jersey panel (white→pale blue, slate-grey digits, blue units, grey + blue sleeve stripes, blue selected tab, blue dot) on the white header; switches Women ⇄ Men by itself every 5 s (slide-in + light-blue→blue 5 s progress bar, pauses on hover, tapping a tab shows it and restarts the 5 s); Women/Men tabs, live d/h/m/s countdown to the selected race (auto-picks the next race), "LIVE · Stage X/N" while racing, "Finished" after; the four jerseys on desktop, white jersey highlighted and the others greyed out until hover; click opens https://www.theuaetour.com/. 2027: Women 3–6 Feb (4 stages), Men 15–21 Feb (7 stages). Add next year's dates in site-data.js when announced. Desktop: brand+clock | counter | buttons (70px); phone: brand+buttons / counter / clock (126px).
- Group ride cards stay green (`--rd-*`; they no longer match the red header = #052e16 → #14532d → #16a34a, lime glow, lime accents). Ride share images (`drawCard` theme `green`, green brand bar) and the ride rows in the Share menu use the same green.
- Before pushing: run `node --check` on the inline script, preview phone (390px) and desktop widths, then confirm the Pages deploy succeeds (re-run it if GitHub reports "No artifacts named github-pages").
